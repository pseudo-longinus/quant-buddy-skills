# 事件窗口计算合同

执行细节见 workflows/event-study.md。旧版多事件 `某天后累加 → 分段最终值` 模板已停用：分段结束、截止日和自然日窗口都可能产生非完整观察期的数值，不能贴上“完整21/252交易日收益”的标签。

## A：单组事件

冻结事件和资产 → `buildEventStudy` 取得价格序列要求 → 用现有完整日收盘序列或 `收盘价(资产)` 取数 → `downloadData(format=csv)` 保存单字段原件 → `buildEventStudy({asset,dates,windows,price_file,as_of})`。

N窗口定义为事件锚点之后N个有效日行情观察，收益为端点价格比值减1。1月21个、1年252个仅为近似，明确披露观察基准。输出每次事件的起止日期与状态，只用完整窗口统计均值。

## B：两组事件

使用相同原始价格文件，mode=compare，并传 group_a_name/group_a_dates、group_b_name/group_b_dates。每组、每事件、每窗口独立计算；不同组完整样本数可以不同。重叠事件不会互相截断，但不能声称它们统计独立。来源、事件分类、缺失样本必须保留。

## C：偏移区间

遵循 event-study.md 的偏移口径表：明确“事件后第a至第b个交易日”为T+a至T+b；包含事件当天计数时第a天为T+(a-1)，第b天为T+(b-1)。用实际日行情序列定位两个端点，计算 `终点价/起点价-1`，分别列出实际日期。缺少任一端点则不计算。

`交易日位移` 的检索说明与当前公式运行时不一致，不作为可执行保证；禁止自然日整数加减模拟交易日。已有单事件 fast_query 返回完整短序列时直接按已验证端点回答，不增加重复下载。

## D：财报超预期分类

按 event-study.md 的正式披露日、外部事实证据和分类门槛逐事件打标；禁止用上涨/下跌反推超预期。分类结果交给B的compare计算，不使用旧分段公式。未确认事件不计入，零有效样本明确说明，不能静默换组。

## 超额收益

用户明确要求时，对资产与基准使用同一实际起止日期并核对共同有效日期；先算两边端点收益，再按已声明定义计算超额。不能把日超额收益累加当作复利超额。
