# Guide · 因子观察台页（commodity-factor-watch）

适用：把"某资产/商品的涨跌怎么看"拆成 **N 个可核对因子** 的观察台页面——原油六因子、美元多空五因子、铜三因子等。目标是让 playbook 命中或用户点名的"N 因子"需求不再落入通用 research-v1 数字卡墙。

页面按本文的结构合同自建，不随技能包附带具体资产示例；编译与验收走 [bespoke 页](bespoke-page.md) 同一条链。

## 为什么不用通用 dashboard

通用看板的默认形态是"数字卡墙 + full-width 图表纵堆 + 文本块垫底"，对因子观察任务有三个结构性伤害：

1. **结论后置**：主判断落进页尾 text 面板，首屏只剩散落数字。
2. **因子失焦**：N 个因子被拆成 N+k 个同级指标卡，"六因子"只剩标题文案。
3. **静态/实时混用**：垫底结论在构建期写死，与顶部实时值漂移（如 SC 实时 734.1、正文写 735）。

## 页面结构合同（自上而下）

```text
眉题（品类 · 刷新状态 · 行情截至/库存截至）
H1（问题式标题）
主结论导语 data-qb-conclusion —— 数据绑定，≥30 字，含关键数值
研究快照注 —— 声明结论为研究生成、数值实时、按各自日期
因子导航 data-qb-factor-nav —— ①..⑥ 锚点胶囊，首屏可见全部 N 个
行情卡 data-qb-metric —— 每卡：值 + 日变化 + 窗口变化 + 自身数据日期
数据新鲜度条 data-qb-fresh-cell —— 每格一种节奏：daily / weekly / snapshot
01 六因子现状 —— data-qb-factor-card 网格（桌面 3 列，768 两列，680 单列）
02 图表取证 —— 1 张主图 full + 其余半宽成组（≤2 列），超 3 张必须折叠或页签
03 口径与来源 —— details 折叠：因子构成表 + 实时/快照边界 + 公式 + 免责
```

每张因子卡五件套，缺一不可：

1. **当前值 + 单位**（data-qb-metric 绑定）
2. **自身数据日期**（来自数据返回，不从系统时间反推）
3. **变化**（日变化 / 窗口变化 / 周环比，按指标频率选）
4. **分位或方向**（data-qb-pbar 分位条 + 圆点位置；窗口在口径表声明）
5. **一句机制解释**（说明"这个因子为什么影响标的价格"，不预测方向、不复述数字）

## 数据绑定规则

- 取数一律走共享内核（`QB.query`）；因子分位/变化是**展示层计算**，不改写源数据。
- 绑定声明在 DOM（`data-metric` / `data-qv`），渲染函数只含通用统计逻辑，不含任何具体业务数值。
- 结论导语由模板拼接 + 关键数值 `<b>` 高亮；数字变化时整句随刷新重算，**不允许构建期写死**。
- 个别产出偶发缺失时：二次取数兜底一次，仍缺则按已到数据渲染并在状态行点名缺失项，不画假值。

## 实时 / 静态边界

- 每个指标带自身日期；混合频率（日频价格 × 周频库存 × 研究结论）必须用新鲜度条显式分层，不得冒充同频。
- 结论的方向表述是**研究快照**：hero 处必须声明分析日与"数值实时、判断快照"的边界。
- 观察日声明写入 `data-qbObservationDates`（数据返回日期集合），口径表逐因子列出数据日期。

## 移动端（390 / 320）

- 首屏顺序与桌面同 DOM 顺序：标题 → 主结论 → 因子导航 → 行情卡 → 新鲜度条；不靠 `order` 修复。
- 六因子导航在 320 也要全部可见（换行成 2×3，不用横向滚动截断）。
- 行情卡值字号 ≥24px；正文 17–18px；表格 ≥14px；H1 ≥28px。
- 因子卡单列堆叠，分位条全宽。

## 验收门槛（verify_page --profile self-built 之外，因子页额外硬门槛）

设计检查（`scripts/dashboard_design_checks.mjs`）对因子页自动执行：

1. **首屏主结论**：`[data-qb-conclusion]` 必须存在、首屏可见、非占位文本。
2. **因子分组可见**：首屏必须能看出 N 组因子（导航胶囊或因子卡 ≥ N−1）。
3. **指标自带日期**：每个 `[data-qb-metric]` 必须含 `20xx-xx-xx` 日期。
4. **图表分组**：非折叠 full-width 图表 >3 张即判失败。
5. **节奏分层声明**：必须存在 `data-qb-fresh-cell`（或等价 cadence 标注）声明实时/周频/快照边界。
6. **public-smoke ≠ 视觉通过**：public-smoke 只证明功能结构，不能作为视觉质量结论；交付页必须跑 self-built / full 三视口 + 截图审阅。

## 禁止

- 不复制参考页文案、主题色或页面专属选择器；只复用结构合同。
- 不为凑满 N 个因子扩大范围——因子与用户问题无关就减 N，并把 N 写进标题。
- 不把分位条当精确刻度；窗口与口径必须在折叠区可查。
- 不在结论里使用"截至今日"这类从系统时间反推的日期。
