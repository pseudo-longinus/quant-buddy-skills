# LIVE / SNAPSHOT 兼容补标

标签是可读性增强，不是新的发布条件。最后检查页面时查看验收结果中的 `data_labels`：它只记录已识别模块的覆盖和诊断警告，不影响原有 code、发布、回复及恢复流程。不能为了缺标重查数据、重建页面、降低内容质量或将动态数据降级为快照。

## 口径

- `LIVE` 表示该模块已接入刷新，数据日期以来源为准；不表示每次请求都成功，也不表示数据日期是今天。
- `SNAPSHOT` 表示固定内容，包括验证后的快照、固定文件和固定研究结论。查询类型 `snapshot` 不直接决定页面标签。
- 标记按模块判断，QBS 查询成功、is_live=true 或已有 Grant 均不能单独使整页成为 LIVE。绑定数据的研究文字可能混合静态判断与动态数字，本轮不自动把它标为 LIVE。
- 未识别、证据不齐、空间不足、无安全标题位置时保留原样，记录诊断；已有明确同义标签不重复添加。日期沿用正文真实日期，不以生成时间冒充数据时点。

标签采用淡绿色 `Live` 与淡紫色 `Snapshot` 小底色矩形，12px字号、3px圆角，不改变正文和标题字体。固定研究可显示 `Snapshot · 分析日 2026-10-14`，验证数据快照可显示 `Snapshot · 截至 2026-10-13`。数据截止日来自既有验证结果；不同字段仍按正文各自日期展示。

固定内容的日期优先使用面板已有的 `analysis_date`、`data_date/as_of`，或标题/文案中明确的分析日、数据日期；页面可选 `analysis_date` 仅作兜底，不能覆盖模块自身历史分析日。以上均为可选元数据，不新增取数或必填字段。无法可靠确认日期时保留 `Snapshot`，不使用 generated_at、captured_at 或文件修改时间替代数据日期。

日期标签空间不足时先缩短为 `Snapshot · 2026-10-14`，再退回 `Snapshot`；完整日期及其含义仍在提示和无障碍名称中。标签本身仍无法放下时继续按原规则跳过，不压缩标题或正文。验收 `data_labels.modules[].dates` 记录已显示日期及 full/date/tooltip 展示方式，仍为非阻断诊断。

## 兼容行为

标准看板及 Compose 在原有构建取数和数据检查通过后，复用模块输出与运行绑定生成标签元数据，在候选哈希和收据生成前写入。渲染器仅在已知标题位置补小徽标；会导致标题换行或溢出的新增徽标立即移除，不改正文、字号、排序、图表和数据内核。不增加网络请求、模型调用、刷新监听或浏览器等待。

标签准备、资源读取、徽标渲染和标签检查分别隔离异常；失败时原流程继续，原有数据和发布错误仍按原规则处理。`data_labels.warnings` 是非阻断诊断，不能据此触发 planned-delivery-recovery 或追加一次发布。

新增标签使页面超过既有 2 MiB 发布上限时，生成器撤销新增补标并保留原内容；原本已超限的页面仍按原规则处理，不能删减内容来容纳徽标。

生成参数 `data_labels:false` 关闭本次补标；环境变量 `QBV_DATA_LABELS=0` 关闭新生成/重编译时的补标。开关不修改已发布页面，普通数据查询与必需交接字段不变。

## 覆盖范围

| 路径 | 行为 |
|---|---|
| 标准看板 / Compose | 对证据完整的数据面板、固定文本与图片补标；混合文字保守留空 |
| 图片 / PDF 承载页 | 在生成器自己的 figure 说明区增加固定文件快照标记；原文件、图片内容不变 |
| 原 HTML 托管 / 保真增强 | 不改保真正文，保留既有 LIVE 机制，已有验收中只记录覆盖 |
| 同页维护 | 既有验收器返回非阻断诊断；不强制迁移旧 DOM |
| 快页 / direct | 不新增浏览器调用或改写服务器模板；仅当原路径使用本地验收器时返回诊断 |
| 历史 / 自定义页面 | 只统计能可靠识别的模块；零识别返回 unrecognized，不宣称全覆盖 |

浏览器结果 `data_labels` 包含 `advisory:true`、`checked`、各视口模块明细及 warnings。缺标、冲突、不可见和检查异常不会进入原有 `problems`。这不是全页面金融事实校验，也不取代原有数据、视觉和公开版本验收。

本轮不做运行时加载/失败/恢复切换、服务端快页模板改造和历史页面迁移。后续授权维护时可逐步扩大兼容覆盖。
