# 国内股指期权槽位页面

用户要求展示沪深300、上证50或中证1000的期权行情、IV、持仓量或成交额时读取。`国内期货期权-*` 行情包含这三个股指，并不限于商品；数据列分别为沪深300主连（IF.CFE / IO）、上证50主连（IH.CFE / HO）、中证1000主连（IM.CFE / MO），括号后半部分是期权品种代码，不是数据列ticker。

## 数据通道

1. 沿正常Trace、QBS先答、模板或自建流程处理。QBS已有本轮计算胶囊时复用；没有时通过bridge按QBS `workflows/cn-index-options.md` 查询精确数据标题与实际资产维度，不以普通股票画像、股指期货价格或ETF期权替代。
2. 行情目录提供 E1/E2 × ATM-CALL/ATM-PUT/25C/25P × 收盘价/隐含波动率/持仓量/成交额32个字段。只验证用户所需槽位、字段和时间范围；标题例如 `国内期货期权-E1-25C-隐含波动率`，各标的实际缺口以查询为准。
3. 使用QBS已验证的完整公式合同登记Formula Package，再按原有收据、资源归属、首次取数及发布验收合同绑定页面；不能将这些目录字段当作 `fast_query` 白名单，也不能用 `kind:option_contracts` 取得行情。
4. `option_contracts`只读取具体合约映射，目前股指映射未开放。若用户还要合约代码、行权价、到期日或换约，保留可交付的行情模块，单独说明映射缺口，不能编造合约或因为该限制删除行情。

## 页面口径

- 标明实际标的、E1/E2、槽位、字段日期和单位；self-IV原始小数0.25展示为25%。数据列使用主连维度不等于股指期权以期货合约为法律标的。
- E1/E2不等于期货主力/次主力；拼接价格变化不等于持有同一合约的收益。
- 页面称“股指期权槽位行情/IV观察”，不能称“完整期权链”。全链须有全部请求到期月、行权价和认购/认沽覆盖证据，32个目录字段不是全合约清单。
- 保留真实缺值和日期，发布可用模块并说明缺口；不能因映射接口拒绝或某槽无值，扩大为全部股指期权数据不可用。
